# GAINROOT™ — Orange Sweet-Potato Energy Bites

> **Small bites. Everyday fuel.**  
> Meet GAINROOT: orange sweet-potato energy bites being developed for a convenient snack between everyday moments.

An informational brand website for **GAINROOT™**, showcasing the product concept, ingredients, development progress, and FAQ.

---

## 🍠 Product Overview

- **Brand:** GAINROOT™
- **Concept:** Baked orange sweet-potato energy bites.
- **Format:** Small baked bites, planned 5 bites per pack.
- **Main Ingredient:** Orange sweet-potato powder.
- **Current Formulation Ingredients:** Orange sweet-potato powder, oat flour, peanut powder, canola oil, sugar, and water.
- **Nutrition Development Target:** Approximately 300 kcal per planned five-bite pack *(formulation target, not a verified nutrition value)*.
- **Positioning:** An everyday energy snack, not a protein supplement or meal replacement.
- **Status:** In development. Recipe, packaging, and final specifications are being refined.

## 🚀 Getting Started

### Prerequisites

- Node.js (v18+)
- npm or yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/Fraziz/gainroot.git
cd gainroot

# Install dependencies
npm install

# Start local development server
npm run dev
```

### Production Build

```bash
npm run build
npm run preview
```
